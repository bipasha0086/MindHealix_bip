# MongoDB Shell (mongosh) Installation Guide for Windows

1. Go to the official MongoDB Shell download page:
   https://www.mongodb.com/try/download/shell

2. Select Windows as your operating system.

3. Download the installer (MSI) and run it.

4. Follow the installation prompts to complete the setup.

5. After installation, open a new Command Prompt or PowerShell window and run:

   mongosh --version

   This should display the installed version, confirming the installation.

6. You can now connect to your MongoDB Atlas cluster using:

   mongosh "mongodb+srv://mindhealix.hwyhunh.mongodb.net/" --apiVersion 1 --username rehanbharat167_db_user --password bipshu123
